# Scalency OS vs GoHighLevel: feature comparison

Status as of 17 November 2026. Based on GoHighLevel's public feature set and its 2026 releases (AI Employee, Voice AI, new workflow triggers, Mobile App 4.0, custom dashboards on all plans).

**Key:** ✅ Live · 🟡 Partly built · 🔜 In the menu as "Soon" (preview page only) · ❌ Not started

| Area | Scalency today | Biggest gaps |

| Conversations | 🟡 Email and SMS | Calls, WhatsApp, social DMs, chat widget |
| Automation | ✅ Strong core | More triggers and steps, AI steps, templates library |

| Lead capture (forms, funnels, sites) | 🔜 | Everything |

| Reputation | 🔜 | Everything |
| Memberships and communities | 🔜 | Everything |

| Agency and team | ✅ Strong | SaaS rebilling, snapshots, white label domain |
